# Этап 5: уверенность и сценарий «не найдено»

Реализована калиброванная оценка того, можно ли доверять top-1 гибридного распознавателя.
Результат теперь имеет три состояния:

- `match` — вернуть один slug;
- `alternatives` — не утверждать top-1, показать top-5 кандидатов;
- `not_found` — сообщить, что надёжного совпадения в локальном каталоге нет.

## Актуальная перекалибровка

После расширения каталога до 2 035 вин и выбора полевых весов `DINO 0,45 / SIFT 0,05 /
OCR 0,50` confidence-модель пересчитана. Текущие пороги: `match` — 0,999968,
`alternatives` — 0,490874. На синтетической проверке это даёт высокую точность принятых
ответов (90,9% на held-out), но лишь 1,2% known-кадров получают автоматический `match`.
Порог получился чрезмерно консервативным из-за требования нулевых ошибок на малом calibration
unknown-наборе; перед production его нужно повторно калибровать на более крупном реальном OOD.

После переноса 10 актуальных карточек «Литавщук» в основной каталог в current-site unknown
наборе осталось 36 независимых бутылок и 72 сгенерированных кадра. Blur во всех них отключён.

## Unknown-набор

Для OOD-проверки используются только российские вина из того же предметного домена. Сборщик
обходит живой каталог [«Своё Вино»](https://vino-svoe.ru/wines) и выбирает позиции, slug которых
нет в локальном снимке из 2 025 карточек.

На 20 сентября 2026 года найдено 46 таких бутылок. Все исходники визуально проверены: это
чистые карточки бутылок, а не дегустации, интерьеры или случайные изображения. Для каждой
бутылки созданы два полевых кадра тем же исправленным генератором, что использовался на этапе 2.

| Показатель                   |               Значение |
| ---------------------------- | ---------------------: |
| Независимых unknown-бутылок  |                     46 |
| Синтетических unknown-кадров |                     92 |
| Calibration                  |  21 бутылка / 42 кадра |
| Held-out                     | 25 бутылок / 50 кадров |

Оба варианта одной бутылки всегда находятся в одном split. Manifest сохраняет исходный slug,
название, производителя, URL карточки и изображения, SHA-256 и все параметры преобразования.

Воспроизведение:

```powershell
uv run vino-collect-unknown --variants 2
```

Артефакты находятся в `data/unknown/stage5/`. Поскольку живой каталог меняется, для
воспроизведения конкретного отчёта нужно сохранять сформированный manifest и исходные WebP.

## Признаки уверенности

Логистическая confidence-модель получает 16 сигналов:

- итоговый hybrid score и margin top-1/top-2;
- embedding score;
- SIFT score и логарифм числа RANSAC-inlier;
- общий OCR score и количество распознанных строк;
- отдельное OCR-подтверждение `title`, `manufacturer`, `grapes` и года;
- согласие top-1 между полным кадром, средним и крупным crop;
- присутствие победителя в top-1/top-5 каждого crop;
- средний score победителя по crop и стабильность этих scores.

Положительный класс — только корректный top-1 известного вина. Ошибочный top-1 известного
вина и любая бутылка вне индекса относятся к небезопасному классу.

Модель обучается только на calibration split. Порог не задаётся вручную: выбирается минимальный
порог, при котором calibration unknown FAR не превышает 2,5%, а приём ошибочного known — 5%.

```powershell
uv run vino-calibrate-confidence --device cuda --workers 3
```

Полученные пороги:

| Порог          |                       Значение |
| -------------- | -----------------------------: |
| `match`        |           confidence ≥ 0,86570 |
| `alternatives` | 0,36998 ≤ confidence < 0,86570 |
| `not_found`    |           confidence < 0,36998 |

## Held-out результаты

Финальная часть содержит 1 626 known-кадров и 50 unknown-кадров от 25 независимых новых
бутылок.

| Метрика                              |        Результат |
| ------------------------------------ | ---------------: |
| Unknown false accept rate, кадры     | **4,00%** (2/50) |
| Unknown FAR, независимые бутылки     | **8,00%** (2/25) |
| Wrong-known accept rate              |        **7,83%** |
| False reject правильных known        |           41,71% |
| Покрытие `match` среди known         |           46,00% |
| Точность среди всех принятых `match` |       **95,60%** |
| ROC AUC safe/unsafe                  |            0,866 |
| Brier score                          |            0,129 |
| Expected calibration error           |            0,033 |

95-процентный Wilson-интервал sample FAR равен 1,10–13,46%, source-level FAR — 2,22–24,97%.
Интервалы широкие из-за небольшого числа новых независимых бутылок; расширение OOD-набора
остаётся обязательным перед production.

Два held-out false accept принадлежат одной визуально почти неразличимой серии Château de Talu:
новые `Красностоп Резерв` и `Каберне Совиньон Резерв` были приняты за находящийся в индексе
`Каберне Фран Резерв`. Это реальный сложный случай, а не изображение другого домена.

Строгий порог сознательно отказывает часто: 41,71% правильных known не получают немедленный
`match`, а переходят в `alternatives` или `not_found`. Это соответствует выбранному приоритету —
качество важнее покрытия.

Полные результаты: `data/artifacts/stage5/stage5_report.json`. Все примеры с confidence,
решением, top-5 и исходными признаками: `confidence_examples.jsonl`.

## Распознавание

```powershell
uv run vino-recognize-confident path/to/photo.jpg --device cuda --local-files-only
```

Пример надёжного результата:

```json
{
  "decision": "match",
  "slug": "priboj-marchenko-beloe-polusuhoe",
  "confidence": 0.9199
}
```

Для неизвестной бутылки `slug` равен `null`. При `alternatives` массив `alternatives` содержит
top-5. Debug-поля сохраняют candidate slug, отдельные признаки, OCR, crop-consistency и timings.

## Скорость

На 20 последовательных прогретых запросах, поровну known и unknown, RTX 4060 + i5-9600KF:

| Метрика  |  Значение |
| -------- | --------: |
| Среднее  | 562,28 мс |
| p50      | 538,39 мс |
| p95      | 762,25 мс |
| Максимум | 774,46 мс |

Confidence-слой почти не добавляет вычислений к этапу 4 и остаётся значительно ниже потолка
10 секунд и первоначальной цели 3 секунды.

## Ограничения

- FAR измерен только на 46 новых российских винах; его нельзя считать production-гарантией.
- Визуально одинаковый новый год или сорт может быть неотличим от позиции в индексе без
  читаемого текста.
- Калибровка пока основана преимущественно на синтетических полевых кадрах.
- Консервативный режим обеспечивает высокую точность принятых ответов ценой покрытия.
- Решение `not_found` не должно автоматически заменяться top-1 на уровне будущего API.
